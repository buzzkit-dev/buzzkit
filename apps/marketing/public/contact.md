# Contact

BuzzKit is built in the open and answered by people. The fastest way to reach the project depends on what you need.

## Email

For questions about the hosted version, self-hosting or anything that does not fit an issue, write to hello@buzzkit.dev. Real people read it, so a clear description of what you are trying to do gets the most useful answer.

## Bugs and feature requests

Bugs, feature requests and questions about the code belong in GitHub issues on the BuzzKit repository: https://github.com/buzzkit-dev/buzzkit/issues. An issue with the request you sent, the response you got and what you expected instead is usually enough to reproduce a problem.

## Following development

Development happens in the main repository (https://github.com/buzzkit-dev/buzzkit) and the iOS SDK repository (https://github.com/buzzkit-dev/buzzkit-ios). Watching either on GitHub is the way to see releases as they land.
