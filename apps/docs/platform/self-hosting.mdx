BuzzKit is open source, and a self-hosted deployment serves the same API as buzzkit.dev. Running it yourself is not something we support yet, though: there is no setup guide, no documented upgrade path between versions, and no support if a deployment breaks.

<Note>
  A complete self-hosting guide is coming when BuzzKit is out of beta. Until then, use [buzzkit.dev](https://buzzkit.dev).
</Note>

## What it will need

A deployment needs a Cloudflare account for Workers, KV, Queues, Durable Objects and Hyperdrive, together with PostgreSQL and Tinybird. Provider credentials, such as an Apple Developer key or a Firebase service account, are uploaded through the dashboard rather than set as environment variables. We plan to simplify this setup before the guide lands, so treat the list as the shape of the thing rather than a checklist to work through.
